# Distinctive by default

AI-assisted design drifts toward one interchangeable look. Use this file in two ways: build each direction from the project's own material (below), then check the result against the recognition list.

## Build from the project's own material

1. **Mine the domain.** List five to ten physical or cultural artefacts of the subject: for a library, spines, catalogue cards, marginalia, call numbers, reading-room lamps; for a bakery, flour-dusted surfaces, paper bags, handwritten chalkboards. Directions come from these, not from a style-of-the-month.
2. **Give each direction one signature move.** One memorable, ownable element: a type treatment, a layout device, an interaction, a texture. Name it explicitly. A direction without one isn't finished.
3. **Commit to scale contrast.** Pair a dramatic display size with quiet body text; let one element dominate each view.
4. **Pair type with intent.** Each typeface earns its role; say why this face suits *this* voice.
5. **Restrain colour.** Mostly neutrals, one committed accent, semantic colours kept separate. Derive the palette from the domain material where you can.
6. **Compose from the content.** Let real content length, image ratios, and task order set the grid.
7. **Write real microcopy.** Specific, in the brand's voice, about this product.

## Recognition list

These are the defaults to recognise. Each is acceptable only when the brief justifies it *and* the ledger records it as a decision.

- One neutral sans (Inter, Roboto, system UI) for every role, with no pairing rationale.
- Purple-to-blue or indigo gradients; gradient-filled headline text.
- The template stack: centred hero, subheading, two buttons, three icon feature cards, logo strip, testimonial carousel, three-column pricing.
- Glassmorphism, blurred colour blobs, or floating 3D shapes used as decoration with no meaning.
- Identical large radii and soft drop shadows on every surface.
- Dark background with a neon accent, chosen by default rather than by brief.
- Uniform spacing and sizes everywhere, so nothing leads.
- Generic icon-in-a-circle feature illustrations, or emoji standing in for imagery.
- Interchangeable copy: "Unlock the power of…", "Seamless", "Revolutionize your workflow".

## The swap test

Before presenting a direction, ask: *could this be dropped onto a competitor's site with only the logo changed?* If yes, push the signature move and the domain material further until the answer is no.

Distinctive still means usable: a signature move never costs legibility, accessibility, or task clarity.

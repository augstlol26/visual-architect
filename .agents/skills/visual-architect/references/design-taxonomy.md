# Design taxonomy

Vocabulary for creative direction. It's for curating, not a menu to recite: pick what fits the brief and explain it through this product. Use the columns to justify a recommendation.

## Art directions

| Direction | Character | Use when | Watch out for |
|---|---|---|---|
| **Editorial** | Type-led, considered grids, publication pacing | Content is the product: journalism, books, portfolios, long reads | Thin content makes it feel empty; needs real copy |
| **Cinematic** | Dramatic scale, controlled reveals, atmosphere | Storytelling launches, film/game, premium product reveals | Heavy media hurts performance; reveals can delay tasks |
| **Minimal** | Restraint, whitespace, precise hierarchy | Tools, professional services, products with strong photography | Slides into generic fast; needs a signature move |
| **Brutalist** | Raw structure, hard contrast, visible system | Culture, art, developer-adjacent brands wanting edge | Usability and accessibility suffer if done carelessly |
| **Neo-industrial** | Technical labels, grids, mono type, utility | Dev tools, hardware, data products, engineering brands | Can feel cold; balance with one humane element |
| **Playful** | Expressive colour, rounded forms, character motion | Consumer, kids, community, casual products | Tiring over long tasks; keep the work areas calm |
| **Luxury** | Restraint, material cues, confident serif or didone | Fashion, hospitality, high-end goods | Low-contrast elegance often fails WCAG |
| **Organic** | Natural forms, soft transitions, earthy palette | Wellness, food, sustainability, craft | Clichés (leaves, beige) unless grounded in real material |
| **Retro-futurist** | Period motifs, contemporary execution | Music, games, nostalgia-led brands | Pastiche risk; pick one era and commit |
| **Swiss / International** | Strict grid, sans type, asymmetric balance | Institutions, design studios, information-dense sites | Severe if imagery and colour are timid |
| **Maximalist** | Layered pattern, colour, collage | Fashion, music, events, youth culture | Hierarchy collapse; anchor with a strict type system |

## Typography moves
Display, headline, body, caption, overline, metadata roles · scale contrast · weight contrast · measure (45–75 ch) · leading · variable axes · fluid type · optical alignment · editorial pull quote · oversized numerals · data/tabular figures · kinetic type.

## Colour and surface moves
Dominant / supporting / accent / semantic / neutral roles · tonal, analogous, complementary, monochrome, high-contrast palettes · elevation · hairline borders · translucency · grain and noise · paper and material textures · duotone. Always verify contrast.

## Image and asset treatments
Art-directed photography · cutout · collage · duotone · monochrome · illustration (flat, textured, line) · diagram · 3D object · procedural or generative graphic. Specify crop, focal point, aspect ratio, overlay, lighting, and responsive art direction (different crops per breakpoint).

## Experience patterns
Progressive disclosure · onboarding · command palette · search-first discovery · faceted filtering · contextual actions · empty-state guidance · inline validation · optimistic UI · saved state · comparison · preview · undo/history · storytelling sequence · focus or reading mode.

## Evaluating a candidate
1. Fit with purpose, audience, and content.
2. Clarity and discoverability.
3. Accessibility.
4. Performance and build cost.
5. Responsive and touch suitability.
6. Consistency with confirmed decisions.
7. Meaning: does it communicate something, or only decorate?

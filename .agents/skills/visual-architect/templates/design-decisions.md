# Design decision log

The single record of what was decided, by whom, and why.

| ID | Area | Decision | Status | Rationale | Blocking? | Date |
|---|---|---|---|---|---|---|
| D-001 | Example | Replace this row | Open question | Why it matters | No | YYYY-MM-DD |

## Status definitions
- **Confirmed by user**: the user explicitly chose or approved it. Changes only on the user's say.
- **Accepted recommendation**: the agent recommended it and the user agreed.
- **Delegated to agent**: the user handed the choice over; the agent decided.
- **Assumption — needs validation**: inferred, not yet checked with the user.
- **Open question**: undecided. Mark `Blocking? Yes` if building can't proceed without it.
- **Rejected**: considered and turned down. Kept so it isn't proposed again.
